# Task Manager CLI

Application CLI de gestion de tâches développée en Dart.

## Fonctionnalités

- Ajouter une tâche
- Lister les tâches
- Marquer une tâche terminée
- Supprimer une tâche
- Sauvegarde dans un fichier JSON

## Concepts utilisés

- Classe abstraite
- Héritage
- Interface
- Génériques
- Exceptions personnalisées
- Tests unitaires

## Lancement

```bash
dart run bin/main.dart
```

## Tests

```bash
dart test
```
